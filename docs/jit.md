# 机器码与 `[[jit]]`

`[[jit]]` 只表达一件事：**这个函数值得在加载时就优化**。它不改变语义——同一个函数带标记和不带
标记，结果（包括 `typeof`）必须完全一致，见 `examples/jit.ant`。

```annota
[[jit]]
sum_to(n)(
    new s = 0
    new i = 0
    while i < n(
        s = s + i
        i = i + 1
    )
    =s
)
```

**不写这个标记也照样优化**：热循环会被解释器自己编译成机器码（§1）。`[[jit]]` 只是把时机提前。

## 1. 自动优化（不需要任何标注）

解释器自己数循环：一个循环的回跳超过阈值（默认 4000 次，`ANNOTA_JIT_THRESHOLD` 可调）后，它会在
运行中把整个函数编译成机器码，并且**当场从当前循环头切过去执行**（on-stack replacement）——不必
等下一次调用，也不用重启程序。翻译不了就安静地继续解释执行。

所以：

| 写法 | 行为 |
| --- | --- |
| 什么都不写 | 热循环跑到阈值后自动编译并接管 |
| `[[jit]]` | 加载阶段就编译（适合"只调用一次、但循环很长"的函数） |
| `ANNOTA_JIT_THRESHOLD=0` | 关闭自动提升（`[[jit]]` 仍然生效） |
| `ANNOTA_NO_JIT=1` | 完全关闭机器码后端，只保留超指令融合 |
| `ANNOTA_JIT_DEBUG=1` | 打印哪个函数被自动编译、哪个不可翻译及原因 |

## 2. 超指令融合（只要走 `[[jit]]` 或自动提升都会做）

融合保持字节码长度不变（空出来的位置填 `nop`），所以所有跳转目标仍然有效：

| 原序列 | 融合为 |
| --- | --- |
| `s = s + k` | `local+=` |
| `s = s - k` | `local-=` |
| `s = s + t` | `local+=local` |
| `i < n` + 条件跳转 | `local<local?` |
| `i < k` + 条件跳转 | `local<imm?` |
| `a[i] = a[i] + k` | `index+=` |

想看自己代码融合成了什么：

```powershell
build\annota.exe check --dump-bc examples\jit.ant
```

## 3. 机器码后端（整个函数可翻译时）

如果函数体全部落在整数子集里，整个函数会被翻译成 x86-64 机器码，调用时直接执行原生代码：

* 允许的指令：局部变量读写、整数加减乘、六种比较、条件跳转、无条件跳转/回跳、返回；
* 整数运算直接在虚拟寄存器上完成（原生栈帧里），没有逐条指令的派发开销；
* **参数与未确定赋值的局部变量在调用前检查**：不是整数就照常解释执行，语义不变；
* 返回值的类型（`int` / `int64` / `bool`）用运行期种类字节记录，因此 `typeof` 与解释器一致；
* 每个"回跳目标且操作数栈为空"的循环头都有一个入口（trampoline：先做栈帧开场再跳到循环头），
  这就是自动提升能在一个函数执行到一半时接管的原因。

翻译不了的情况（字符串、列表、调用、闭包、创建闭包、容器操作、无法证明类型的运算……）会安静地
退回解释器，所以带不带标记都不会让程序出错。

## 4. 实测

同一台机器（MinGW-w64 g++ 13.1，`-O2`，单核）：

| 工作 | 未优化 | 机器码 |
| --- | --- | --- |
| `while` 循环 40 万次（不写标记，靠自动提升） | 69 ms（纯解释） | **约 1 ms** |
| `while` 循环 40 万次（写 `[[jit]]`） | — | **不到 1 ms** |
| 10 次加法循环体 30 万次 | 192 ms | **1 ms** |
| `annota bench` 的 `vm jit on loop` | 175 ns/迭代（关闭后端） | **1.2–1.5 ns/迭代** |

对照的 C++ 基准（`tools/cpp_baseline.cpp`）里，同一个循环是 0.21 ns/迭代，也就是说整数热循环已经
落在 C++ 的个位数倍以内，而不是几百倍。复现方式见 [tools.md](tools.md) §7。

## 5. 什么时候该用哪条路线

| 情况 | 建议 |
| --- | --- |
| Annota 里的纯整数循环 | 什么都不用做（自动提升）；想提前编译就写 `[[jit]]` |
| 算法内核（排序、筛法、矩阵、字符串扫描……） | 链接 C++，见 [FFI](ffi.md) |
| 只是写法啰嗦、想复用 | 标准库脚本模块（`lib/*.mod`） |
